# Reanty.

## Chạy local

```bash
cd ....
python server.py
```

Mở trình duyệt tại:

- Website: `http://localhost:8000/`

- Data server: `http://localhost:8000/data/stays.json`

- Site data: `http://localhost:8000/data/site.json`

- Contact data: `http://localhost:8000/data/contact.json`

- Data endpoint mẫu: `http://localhost:8000/data/newsletter.json`
